# Репостер Telegram → ВК и Дзен

Каждые 15 минут забирает новые посты из Telegram-группы, публикует их на стене сообщества ВК
и собирает RSS-ленту, из которой посты автоматически появляются в Дзене.

## RSS для Дзена

Лента и страницы материалов лежат в `docs/` и копируются в репозиторий сайта
`pandagrouppro-glitch.github.io`, подключённый в Студии Дзена (Настройки → Свой сайт → RSS).

Требования Дзена, которые для этого выполняются:

- на первую проверку в ленте должно быть не меньше 10 материалов;
- у каждого материала обложка в `enclosure` и тип публикации в `category`;
- ЧПУ-ссылки без параметров: `/p/<id>-<заголовок>/`;
- картинки лежат на своём домене (`docs/img`), минимальная ширина 700 px.

Материалы с `<category>native-draft</category>` попадают в черновики Студии, остальные
публикуются на канале сразу. Архивные посты помечены черновиками, чтобы не дублировать
то, что уже опубликовано в Дзене руками.

После изменения ленты её нужно заново отправить на проверку в Студии Дзена.

## Установка

1. Создать репозиторий на GitHub и загрузить туда файлы: `repost.py`, `state.json`, `.github/workflows/repost.yml`.
2. Settings → Secrets and variables → Actions → Secrets, добавить:
   - `TG_BOT_TOKEN` — токен бота (бот должен быть админом группы);
   - `TG_CHAT_ID` — id группы-источника (например `-1001234567890`);
   - `VK_TOKEN` — ключ доступа сообщества с правами «Стена» и «Фотографии»;
   - `VK_GROUP_ID` — числовой id сообщества без минуса.
3. Там же во вкладке Variables можно задать `TOPICS` — id тем через запятую (пусто = все темы).

## Проверка

```bash
TG_BOT_TOKEN=... TG_CHAT_ID=... VK_TOKEN=... VK_GROUP_ID=... python3 repost.py --dry-run
```

`--dry-run` ничего не публикует и не меняет `state.json`, только печатает, что было бы отправлено.

## Ограничения

- Видео, видеокружки и опросы пропускаются — ВК их через API принимает иначе.
- Альбомы из нескольких фото собираются в один пост ВК.
- Telegram отдаёт обновления один раз, поэтому `state.json` коммитится обратно в репозиторий; удалять его нельзя.
- Картинки постов хранятся в `docs/img` — их нельзя удалять, иначе материалы в Дзене останутся без медиа.
- Бот должен быть админом группы, иначе Telegram не отдаёт ему обычные сообщения.
