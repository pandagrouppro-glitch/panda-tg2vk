# Репостер Telegram → ВК

Каждые 15 минут забирает новые посты из Telegram-группы и публикует их на стене сообщества ВК.

## Установка

1. Создать репозиторий на GitHub и загрузить туда файлы: `repost.py`, `state.json`, `.github/workflows/repost.yml`.
2. Settings → Secrets and variables → Actions → Secrets, добавить:
   - `TG_BOT_TOKEN` — токен бота (бот должен быть админом группы);
   - `TG_CHAT_ID` — id группы-источника (например `-1001234567890`);
   - `VK_TOKEN` — ключ доступа сообщества с правами «Стена» и «Фотографии»;
   - `VK_GROUP_ID` — числовой id сообщества без минуса.
3. Там же во вкладке Variables можно задать `TOPICS` — id тем через запятую (пусто = все темы).

## Проверка

```bash
TG_BOT_TOKEN=... TG_CHAT_ID=... VK_TOKEN=... VK_GROUP_ID=... python3 repost.py --dry-run
```

`--dry-run` ничего не публикует и не меняет `state.json`, только печатает, что было бы отправлено.

## Ограничения

- Видео, видеокружки и опросы пропускаются — ВК их через API принимает иначе.
- Альбомы из нескольких фото собираются в один пост ВК.
- Telegram отдаёт обновления один раз, поэтому `state.json` коммитится обратно в репозиторий; удалять его нельзя.
- Бот должен быть админом группы, иначе Telegram не отдаёт ему обычные сообщения.
